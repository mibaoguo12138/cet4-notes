# 强调句 (Emphasis)

## It is/was... that/who 强调结构

```
公式: It is/was + 被强调部分 + that/who + 其余部分

普通句: I met an old friend in the street yesterday.
强调时间: It was yesterday that I met an old friend in the street.
强调地点: It was in the street that I met an old friend yesterday.
强调人: It was I who met an old friend in the street yesterday.
```

## 写作中的强调升级

```
普通: I will never marry you.

升级方式:
1. 定语从句: You are the man who I will never marry.
2. 倒装: Never will I marry you.
3. It强调: It is you that I will never marry.
4. 句型套用: It is beyond dispute that I will never marry you.
```

## 六级写作升级链

```
普通句: Reading books is important.

升级链:
1. Reading books is thought to be essential.
2. It is widely accepted that reading books is vital.
3. It is with the rapid development of Chinese economy that reading books is significant.
4. So important is reading books that more time should be spared.
5. Reading books plays a key role in our life, which can broaden our horizons.

→ 逐步添加: 被动语态 → 主语从句 → 强调句 → 倒装句 → 定语从句
```
