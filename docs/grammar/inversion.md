# 倒装句 (Inversion)

## 否定词/短语前置倒装

| 句型 | 例句 |
|------|------|
| Never... | **Never** have I been so happy. |
| Under no circumstances... | **Under no circumstances** can we ignore the severity of sth. |
| Not only...but also... | **Not only** do we demand quantity **but also** quality. |

## Only + 状语前置倒装

```
When love comes, I will hold his hands.
→ Only when love comes will I hold his hands.
```

## So + adj. + that 倒装

```
Reading books is so important that more time should be spared.
→ So important is reading books that more time should be spared to appreciate masterpieces.
```

## as引导的让步状语从句 (必须倒装)

```
Popular as they are, these half-moon-shaped dumplings are by no means quick to make.
尽管饺子很受欢迎，但制作起来绝不快捷。

Young as he is, he knows a lot.
他年纪虽小，懂得不少。
```

## 倒装升级案例

::: tip 写作升级技巧
```
普通: Reading books is important.
升级1: Reading books is thought to be essential.
升级2: It is widely accepted that reading books is vital.
升级3: So important is reading books that more time should be spared.
升级4: Reading books plays a key role in our life, which can broaden our horizons.
```
:::
