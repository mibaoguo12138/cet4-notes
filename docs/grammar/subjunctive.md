# 虚拟语气 (Subjunctive Mood)

## 基本结构

| 条件 | If 从句 | 主句 |
|------|---------|------|
| 与**过去**事实相反 | If + **had done** | **would have done** |
| 与**现在**事实相反 | If + **did/were** | **would do** |

## 例句

```
与过去:
If I had stayed in business, I might be a really wealthy man today.
如果我当初留在商界，现在可能是个富翁。(事实上没有)

If I had started earlier, I would be at the station now.
如果我早点出发，现在已经在车站了。

与现在:
If I were you, I would study harder.
如果我是你，我会更努力学习。
```

## 翻译中的虚拟

```
1. If we had had enough time, we would have carried out the plan.
   如果我们有足够时间，就会执行这个计划了。

2. If I had attended the meeting, I would know the decision now.
   如果我参加了会议，现在就知道决定了。

3. If the ticket had not been so expensive, I could have afforded it.
   如果票不那么贵，我就买得起了。
```

## "not for a moment" 强调否定

```
I do not for a moment mean to speak poorly of business.
我丝毫没有贬低经商的意思。

He did not for a moment want to hurt your feelings.
他丝毫没想伤害你的感情。
```
