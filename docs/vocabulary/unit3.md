## 课文核心句型

### as引导原因
```
As a doctor, too, he is especially conscious of the many dangers surrounding us.
作为医生，他对身边的危险也特别敏感。
```

### so...that... 结果状从
```
This material is so heavy that it would pull you down.
这料子这么重，会把你压坏的。
```
