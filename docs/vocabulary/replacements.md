# 高级替换词速查

> 写作中替换基础词 = 提分关键！

## 动词替换

| 基础词 | 高级替换 |
|--------|----------|
| **think** (认为) | believe, claim, maintain, argue, insist, hold the view/belief that |
| **cause** (导致) | lead to, give rise to, contribute to, result in, be responsible for |
| **solve** (解决) | resolve, tackle, cope with, deal with, address |
| **use** (利用) | utilize, make use of, take advantage of, employ, harness |
| **improve** (改善) | enhance, promote, strengthen, boost |
| **change** (改变) | transform, alter, shift, convert |

## 形容词替换

| 基础词 | 高级替换 |
|--------|----------|
| **good** (好的) | beneficial, conducive, advantageous, favorable, positive |
| **bad** (坏的) | harmful, detrimental, disadvantageous, negative, adverse |
| **important** (重要的) | significant, vital, essential, crucial, indispensable, critical |
| **many** (许多) | numerous, countless, a variety of, quite a few, a multitude of |
| **very** (非常) | exceedingly, extremely, remarkably, incredibly, enormously |
| **big** (大的) | substantial, considerable, enormous, tremendous, massive |

## 连接词替换

| 基础词 | 高级替换 |
|--------|----------|
| **because** (因为) | due to, owing to, thanks to, as a consequence of, on account of |
| **but** (但是) | however, nevertheless, nonetheless, on the contrary, by contrast, whereas |
| **so** (所以) | therefore, thus, consequently, as a result, accordingly, hence |
| **and** (和) | moreover, furthermore, additionally, in addition, besides, what is more |
| **about** (关于) | concerning, regarding, with regard to, as for/to, in terms of, when it comes to |
| **should** (应该) | be supposed to, be expected to, it is essential that, it is advisable that |

## 名词替换

| 基础词 | 高级替换 |
|--------|----------|
| advantage | benefit, merit, strength, virtue |
| disadvantage | drawback, demerit, weakness, shortcoming |
| chance | opportunity, prospect |
| problem | issue, challenge, obstacle, dilemma |
| result | consequence, outcome, effect |
| development | advancement, progress, evolution |

## 副词替换

| 基础词 | 高级替换 |
|--------|----------|
| more and more | increasingly, an increasing number of, growing |
| mainly | primarily, principally, chiefly |
| almost | virtually, practically, approximately |
| quickly | rapidly, swiftly, promptly |
| clearly | obviously, apparently, evidently, undoubtedly |

## 高分短语替换

| 基础表达 | 高分表达 |
|----------|----------|
| I think | From my perspective, / It is my belief that |
| more and more people | an increasing number of people |
| in modern society | in contemporary society |
| should pay attention to | should attach great importance to |
| be good for | be beneficial to / be conducive to |
| be bad for | be harmful to / be detrimental to |
| can't be ignored | can't be neglected / overlooked |
