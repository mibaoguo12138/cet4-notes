# 写作高分万能句

## 开头段句式

| 场景 | 句型 |
|------|------|
| 名言警句破题 | Reading this famous saying, we can naturally perceive its connotation that + 名言内涵 |
| 名言警句破题 | This famous saying conveys a universal fact/phenomenon that + 名言意义 |
| 漫画描述 | It is vividly/clearly depicted in the picture that + 人物/话语/事件 |
| 漫画描述 | Given is a simple/ironical but thought-provoking picture/cartoon, in which + 内容 |
| 现象引入 | Recently the issue/problem of... has been in the limelight / brought into focus |
| 现象引入 | Nowadays, it is undeniable that... has almost become the biggest concern of the present-day world |

## 表达观点万能句

```
People's views on… vary from person to person.
(人们对……的观点因人而异)

Some hold that… However, others believe that…
(有些人认为……然而其他人却认为……)

Attitudes towards… vary from person to person.
(人们对待……的态度因人而异)

Different people hold different attitudes towards…
(不同人对……持不同态度)

There are different opinions among people as to…
(对于……人们的观点大不相同)
```

## 中间段展开句式

| 场景 | 句型 |
|------|------|
| 并列 | For one thing, ... For another, ... |
| 对比 | On the one hand, ... On the other hand, ... |
| 递进 | First of all, ... In addition, ... In the end, ... |

## 结尾段总结句式

| 英文 | 中文 |
|------|------|
| On the whole / All in all / Overall | 总体而言 |
| In conclusion / In summary / In general | 总之 |
| Generally speaking / As a whole | 一般来说 |
| To sum up / To conclude | 综上所述 |
| In short / In brief / In a word | 简而言之 |

## 提出建议万能句

| 英文 | 中文 |
|------|------|
| It is high time that we put an end to the (trend). | 是该停止这一趋势的时候了 |
| There is no doubt that enough concern must be paid to the problem of… | 毫无疑问应对该问题予以足够重视 |
| Only in this way can we… | 只有这样，我们才能…… |
| Spare no effort to + V. | 不遗余力地去…… |
| Obviously, if we want to do something … it is essential that… | 显然，如果我们想做某事，很重要的是…… |
