## 七大作文题型

| 题型 | 适用场景 |
|------|---------|
| 解决方法型 | 提出问题的解决途径 |
| 说明利弊型 | 对比事物优缺点 |
| 阐述主题型 | 从名言或主题出发论述 |
| 对比观点型 | 论述对立观点并给出看法 |
| 社会问题型 | 探讨社会热点原因及解决方法 |
| 图表式作文 | 描述图表并分析变化原因 |
| 图画式作文 | 根据漫画描述社会现象 |
